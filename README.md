## Overview

This is a polished, responsive portfolio for **Aman Sharma**, a B.Tech Information Technology graduate focused on Java, Spring Boot, REST APIs, databases, cloud tools, and full-stack product delivery. The site highlights professional experience, engineering projects, certifications, downloadable resume, and contact links in a clean recruiter-friendly layout.

## Highlights

- Responsive Next.js portfolio with a polished modern interface.
- GSAP-enhanced motion for smooth, tasteful section animations.
- Professional hero/about area with updated profile photo.
- Recruiter-friendly work experience, education, project, and certification sections.
- Updated resume download support.
- Project thumbnails and institution/company branding assets.
- Production-ready build configuration for Vercel.

## Run Locally

```bash
git clone https://github.com/Softeraman/portfolio-aman.git
cd portfolio-aman
npm install
npm run dev
```

Open:

```txt
http://localhost:3000
```

## Production Build

```bash
npm run build
npm start
```

## Project Structure

```txt
src/
  app/
  components/
  data/
    resume.tsx
  lib/

public/
  pfp.jpg
  resume.pdf
  project and brand assets
```

## Customize Content

Most portfolio content can be edited from:

```txt
src/data/resume.tsx
```

Update personal details, social links, skills, experience, education, projects, certifications, and resume URL from that file.
