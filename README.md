## Installation

Clone the repository:

```bash
git clone https://github.com/Softeraman/portfolio.git
```

Move to project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
